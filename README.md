## 优化、标准、国际：三条线路分别解决什么问题

优化线路的走向是电信去回程走 CN2、移动和联通走 CMIN2。这两个都是中国大陆方向的高质量承载网，CN2 的拥堵程度明显低于普通 163 骨干，CMIN2 是移动侧的精品网。对三网用户来说，这条线的晚高峰表现最值得期待，代价是同配置下价格最高。

标准线路的回程大致相当于直连，不做运营商级别的专门调度。它比国际线路强的地方在于回中国大陆不走绕路，但高峰期能不能稳住要看当时链路拥塞情况。预算卡得紧、又不想完全放弃大陆访问体验，选这档。

国际线路是标准国际 BGP，不做中国大陆优化，优势在国际互联和北美方向的访问质量。访问者主要在北美、做国际站、跑 CDN 回源，这档最划算，1Gbps 端口只要 $29.99/年。

按运营商对应一下：电信宽带为主，优化档的 CN2 是你能在这家买到的最好线路；移动或联通为主，优化档的 CMIN2 同样对口。三网混合、访客来源杂，还是优化档省心，多花的那 $25 摊到一年里不到每月 15 块人民币。

## $24.99 和 $49.99 的差别，值不值这 $25

两个价格的核心差异是端口：入门档 20M，高端档 1Gbps，线路都是优化档。$25 一年的差价，换来的是单线程下载从 2.5MB/s 提升到百兆每秒级别的水位。

不过这 $25 不是所有人都该花。20M 端口配不限流量，理论上一个月满速跑也就 6.4TB 左右，对个人小站、API 中转、轻量代理这类用途，20M 的并发承载已经够用。真正需要 1Gbps 的场景是多人共用、视频中转、大文件分发，或者你明确知道会跑满带宽。

反过来，30M 端口配 1T/月 流量这一档要留意配比：30M 满速跑满 1T 只需要三天出头，也就是说流量额度会先于端口用尽。如果你的业务是持续传输，1T 的月额度比端口速度更可能成为瓶颈，这种时候要么选不限流量的 20M 档，要么直接上 1Gbps + 1T 档并接受超额后的处理规则。

同样的判断适用于标准线路：50M 不限流量比 100M + 1T 更适合持续小流量，100M + 1T 更适合短时高并发的建站。价格一样，选错方向就是白花钱。
